# Financy Front-end

Aplicação React + TypeScript + Vite para gerenciar receitas, despesas e categorias pela API GraphQL.

## Executar localmente

1. Instale as dependências com `pnpm install`.
2. Copie `.env.example` para `.env` e ajuste `VITE_BACKEND_URL` se a API não estiver em `http://localhost:4000/graphql`.
3. Inicie a API em `../backend`.
4. Execute `pnpm dev` para abrir a interface em `http://localhost:5173`.

Para gerar a versão de produção, execute `pnpm build`.
